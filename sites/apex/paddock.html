Open practice

Following at race pace

Run a repeatable traffic drill before your first sprint.

Baseline
Give each driver a clear lap on the same fuel load. Pick a braking marker and a reference gap before pairing up.
Follow
Keep the same reference gap for three laps. Start braking early enough to keep the same gap on entry. Use the replay to see where the two lines diverge.
Swap
Switch the leader and repeat. Compare one corner at a time and agree on an approach before reducing the gap.

Team endurance

The driver swap

Make the changeover routine boring before race day.

Before the lap
Confirm fuel, tyres and the next driver in voice chat. Agree on who calls the pit entry and who confirms the changeover.
At the line
Practise engaging the limiter before the line and stopping on the marker. Do a dry run of the simulator’s swap procedure before adding a tyre change.
At pit exit
Read the relative timing and mirror before merging. Treat the first lap after the swap as a reference lap to check the new driver’s controls.

Driver setup

Build a repeatable rig

Set up the wheel, pedals and field of view before changing the car.

Calibrate
Place the seat so you can apply full brake pressure while staying supported. Set the input range and verify that the pedals return to zero.
Check sightlines
Set the field of view based on the screen size and distance. Check that you can see the apex and the essential timing information without leaning.
Save a baseline
Write down the seating position, steering range and pedal settings. Save a copy in the simulator so a new profile is easy to compare.
