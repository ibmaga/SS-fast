Transfer help

Common questions

Questions that affect the estimate, original transfer and set of files you keep.

How do different formats share an estimate?

Add one transfer line per group of items with the same recorded minutes, format and restoration option.

Can I keep both versions?

Yes. Plan for both WAV copies in the archive calculator when you want both versions lossless.

What if the listed length is only approximate?

Start from the label and record assumptions beside the estimate. Billed minutes depend on the recorded material transferred.

How is the comparison timed?

Each demonstration pair is the same duration. Switching versions carries the player time into the selected track.

Which sample should I use?

Choose by the main issue you hear. Pitch drift, impulses, dropouts and steady noise call for different listening checks.
